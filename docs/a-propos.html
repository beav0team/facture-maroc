À propos de Facture Maroc

Mis à jour le 10 novembre 2026 · Yassine, développeur de l’application

Facture Maroc est une application Android de facturation et de gestion de stock, faite pour les commerces marocains : factures, devis, bons de commande, tickets, avoirs, avec les mentions légales du pays. Elle fonctionne hors ligne, sans compte, et sans aucune permission réseau.

Pourquoi une application hors ligne

Un commerçant qui facture dans une boutique, un atelier ou un souk n’a pas toujours de réseau, et n’a pas envie que ses prix d’achat, ses clients et ses marges partent chez un hébergeur qu’il ne connaît pas. La facturation est aussi une obligation qui survit à une coupure : un document doit pouvoir être établi, imprimé et retrouvé le jour où la connexion tombe.

L’application n’a donc pas la permission INTERNET. Ce n’est pas un réglage que l’on peut désactiver : la permission n’existe pas dans le manifeste, et Android refuse alors toute connexion sortante. Le téléphone ne peut rien envoyer, même si quelqu’un le lui demandait.

Ce que contient une version

  • Dix types de documents, chacun avec sa propre numérotation : facture, devis, bon de commande, ticket 80 mm, avoir, proforma, facture d’acompte, facture de régularisation, facture simplifiée, facture à l’export.
  • Six modèles imprimables, dont un format ticket pour imprimante de comptoir.
  • Mentions légales : ICE, IF, RC, patente, CNSS, TVA par ligne, montant arrêté en toutes lettres.
  • Stock mis à jour à l’émission, rendu par un avoir ; achats, inventaire, valorisation au coût moyen ou FIFO, marge par document et par article.
  • Sauvegarde dans un fichier que vous gardez, export XML (UBL 2.1) et CSV pour le comptable.

Où en est le projet

L’application est en test fermé sur Google Play ; la version publiée ici est la 0.11.1, et le code source est public. Les captures d’écran du site montrent une base de démonstration, pas les données d’un vrai commerce.

Le code est écrit en Kotlin et Jetpack Compose, sans base de données : les documents sont des fichiers JSON, lisibles avec un simple éditeur de texte, et sauvegardables sans outil propriétaire. Ce choix coûte un peu de performance sur de très gros volumes ; il garantit qu’un document reste lisible dans dix ans, ce qui est la durée de conservation attendue d’une facture.

Ce que le site ne fait pas

  • Aucun compte, aucune inscription, aucune newsletter.
  • Aucun pistage publicitaire, aucun script tiers, aucun cookie.
  • Aucune promesse de conformité que je ne peux pas tenir : la facturation électronique marocaine n’a pas encore de spécifications techniques publiées, et l’application ne prétend donc pas être « conforme DGI ».
