Écrire au développeur

Mis à jour le 12 novembre 2026 · réponse en quelques jours

FactureApp est développée par une seule personne. Le plus direct est l’e-mail : contact@factureapp.ma. Pour un défaut reproductible, le dépôt GitHub accepte les rapports d’anomalie.

Par e-mail

contact@factureapp.ma

Utile pour : une question avant de commencer, un problème sur vos documents, l’activation du plan Pro, une remarque sur une phrase du site ou d’un guide.

Ce que je ne peux pas faire : vous conseiller sur votre régime fiscal, valider la conformité de votre facturation, ou récupérer des données effacées. Pour ces trois cas, votre comptable est la bonne personne.

Sur GitHub

github.com/beav0team/facture-maroc/issues

Le code est public. Un rapport d’anomalie utile contient la date, le navigateur ou le modèle de téléphone, et les étapes qui reproduisent le problème. Les données d’un vrai commerce n’ont pas leur place dans un ticket public : décrivez le cas avec des montants fictifs.

Ce qu’il n’y a pas sur cette page

Pas de formulaire, pas de champ e-mail à remplir, pas de base de données de contacts. Un lien mailto: suffit, et il ne laisse aucune trace côté serveur.
